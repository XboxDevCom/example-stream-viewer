# Example: Stream Viewer

A stream viewer example running with UWP technology on the Xbox One, demonstrating WebView with multiple streaming platforms (Twitch, Kick, YouTube Live, Trovo, WASD.TV).

## Getting Started

Please follow our [tutorial](https://xboxdev.com/tutorials/) to create your own stream viewer application.

## Supported Platforms

* **Twitch** - https://player.twitch.tv/
* **Kick** - https://player.kick.com/
* **YouTube Live** - https://www.youtube.com/embed/
* **Trovo** - https://trovo.live/
* **WASD.TV** - https://wasd.tv/

## Features

* Multi-platform stream viewing via WebView
* Channel input with validation
* Quick-select preset channels (shroud, xQc, pokimane, summit1g, caseoh)
* Gamepad navigation with XYFocus support
* Xbox One optimized UI (RequiresPointerMode, UseVisible bounds)
